# QazAirPress — статический предпросмотр

В этой директории находятся все изменения. Остальные проекты репозитория не затрагиваются.

## Сборка

Python 3.10+; сторонние библиотеки не нужны:

```sh
python3 scripts/build.py
python3 scripts/audit.py
node --check assets/site.js
bash -n deploy-qazairpres.sh
```

Команда строит 28 HTML-страниц из `scripts/build.py` и `data/products.json`. У всех страниц предпросмотра остаётся `noindex,nofollow,noarchive`. Клиентские фильтры не создают индексируемых посадочных страниц.

## Отдельный экспорт для production

```sh
python3 scripts/build.py --production --output /tmp/qazairpress-production
python3 scripts/audit.py --root /tmp/qazairpress-production --production
```

Экспорт включает только HTML, assets, robots, sitemap и `.nojekyll`. Он не изменяет файлы предпросмотра. Путь внутри этой директории для production запрещён. 26 основных страниц получают `index,follow`; A569 и политика передачи данных сохраняют `noindex`. URL каталога и разделов канонизированы с завершающим `/`.

Это **экспорт файлов**, не публикация. `deploy-qazairpres.sh` — существующий VPS-компонент; его подготовка файлов обновлена для использования этого экспортера. Не запускайте его до решения вопросов из QA. Во время редизайна он не выполнялся, основной домен не изменялся.

## Заявки

`assets/site.js` валидирует форму и открывает WhatsApp с моделью, городом и параметрами. Пользователь самостоятельно подтверждает отправку. PHP, Telegram, база обращений и серверная отправка не используются. При отключённом JavaScript ссылки на WhatsApp остаются доступны.

## Источники и проверка

- `data/products.json`: значения, дата проверки и исходная карточка каждого товара.
- `data/image-provenance.json`: происхождение изображений, хэши, спорные соответствия и статус прав использования.
- `DESIGN.md`: дизайн-система.
- `reports/QA.md`: выполненные проверки и незавершённая приёмка.
- `reports/CONTENT-AUDIT.md`: выводы по данным и необходимые материалы.

Меняйте данные и шаблон, затем пересобирайте страницы. Не редактируйте характеристики только в сгенерированном HTML: следующий запуск их перезапишет.
