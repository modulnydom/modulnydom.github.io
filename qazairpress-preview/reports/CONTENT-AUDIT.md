# Аудит содержания и изображений

## Исходный проект

Изучены все 28 HTML-страниц, общий CSS, оба старых JS-файла, каталог, таблицы 23 товаров, изображения и production-скрипт. В исходном CSS был некорректный фрагмент перед `:root`; часть поведения дублировалась; товарные таблицы зависели от отдельного скрипта с селектором, не совпадающим с фактической разметкой. В заявках терялись отдельные параметры, использовались буквальные `\\n`. В карточках присутствовали неподтверждённые статусы наличия. Исправлены ссылки контактов и единый путь политики для любого размещения.

## Расхождения

- ABK: технические таблицы указывают 8/10/16 **атм**, тогда как структурированные поля продавца содержат МПа и другие противоречия. Сохранены единицы таблицы, расхождения отмечены. Пересчёт атм в бар без указания вида давления не подменяет паспорт.
- ABK15-16: в таблице расход 1,18 м³/мин, в другом поле ошибочно 1180 м³/мин; мощность в одном поле ошибочно в ваттах. Использована техническая таблица. Заявленный комплект не считается подтверждением класса воздуха для конкретного лазера.
- РВ 500/10: в структурированном поле указаны 500 м³ вместо 500 л; давление встречается в бар и атм. В описании — 500 л, 10 атм. Гарантийные условия, арматура, паспорт и допустимое рабочее давление подлежат согласованию.
- РВ 900/10: производитель в карточке неоднозначен; исключены неподтверждённые марки и параметры.
- A569: источник содержит автомобильную совместимость; применение в промышленном компрессоре не подтверждено. Карточка сохранена с явным статусом проверки; не рекомендуется автоматически и исключена из production sitemap.
- 66094172EF/66094212EF: на фото BOREAS, описание содержит другую марку. Бренд не подставляется в Schema.org; расхождение показано пользователю.
- Цены сверены по карточкам, для масел сохранена единица ₸/л. Наличие, сроки и гарантия не экстраполируются с маркетплейса на собственные коммерческие обязательства.

## Фотографии и права

Удалены из отображения и исходных assets все старые категории/цеха/галереи/industrial-изображения без надёжного происхождения. Они не выдаются за поставки компании. В первой версии новые AI-изображения не создавались. По следующему прямому запросу пользователя добавлены три отдельно обозначенные ИИ-визуализации отраслевого применения, основанные на фотографиях реальных моделей ABK15-10TB, ABK15-16 и ABK37-8TB. Товарные фотографии ими не заменялись.

На первом экране используется подписанная визуализация ABK15-16, подготовленная на основе фотографии этой модели. Исходные товарные фотографии сохраняются на страницах моделей. Используются только фотографии с привязкой к тому же источнику; на сайте нет внешних hotlink-запросов к Satu. Имеются размеры WebP 440 и 1000 px; меньшие исходники не увеличивались.

Открытая лицензия на повторное размещение фотографий не найдена. Пользователь поручил переработать сайт той же компании, но это не подтверждает независимым образом владение правами. До production требуется подтверждение владельца о правах/разрешении на фотографии. Закрытый предпросмотр не считается получением лицензии.

Для семи позиций индивидуальное соответствие фото не подтверждено, поэтому вместо подмены указан запрос фотографии:

| Позиция | Что требуется |
| --- | --- |
| ABK22-8TB | Индивидуальный снимок с читаемой маркировкой; нынешний фронт похож на общую фотографию серии |
| ABK55-8TB | Индивидуальный снимок; исходный файл идентичен фото ABK75 |
| ABK75-8TB | Индивидуальный снимок; исходный файл идентичен фото ABK55 |
| РВ 500/10 | Фото с маркировкой объёма и паспортом сосуда |
| РВ 900/10 | Фото с маркировкой объёма; продавец использует визуально тот же ресивер |
| Сепаратор 135/170 × 200 | Фото с подтверждением типоразмера и масштаба |
| Сепаратор 170/200 × 230 | Фото с подтверждением типоразмера; близкая к предыдущей фотография |

Общее изображение ресивера используется только в категории «Ресиверы» как фото серии РВ, без утверждения объёма. Полные URL и хэши исходных файлов — в `data/image-provenance.json`.

Архив `картинки.rar` не прочитан: превышен лимит transfer-инструмента 32 MiB. Для следующего прохода нужны отдельные изображения или архивы до 32 MiB с моделями и сведениями о правах. Документированные фотографии отраслевого применения и кейсы поставок не предоставлены. По отдельному запросу пользователя блок отраслей дополнен подписанными ИИ-визуализациями, без утверждения о выполненной поставке.
