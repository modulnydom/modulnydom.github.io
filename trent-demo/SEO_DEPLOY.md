8. Confirm production nofollow/noindex aren't set by HTTP headers or robots; ensure URL self-canonical.
9. Verify images can be used commercially. Don't claim photos are actual fleet without verification.
10. Run crawl: 36/36, unique titles, descriptions, h1, canonical, breadcrumb schema, no broken links, mobile viewport, 200 statuses.
