Калькулятор себестоимости импорта из Вьетнама в Казахстан

Бесплатный калькулятор ориентировочной себестоимости импортной партии: товар, доставка, страхование, пошлина, НДС и дополнительные расходы.

Рассчитайте полную стоимость партии

Введите суммы в одной валюте. Калькулятор поможет сравнить предложения и оценить себестоимость единицы товара. Ставки пошлины и НДС необходимо самостоятельно уточнить для конкретного товара, даты и таможенного режима.

Результат

Заполните поля и нажмите «Рассчитать».

Что входит в расчёт

  1. Стоимость товара: цена × количество.
  2. Расчётная таможенная база: товар + доставка + страхование. Фактическая таможенная стоимость определяется по применимым правилам.
  3. Ориентировочная пошлина: база × введённая ставка.
  4. Ориентировочный НДС: (база + пошлина) × введённая ставка.
  5. Полная стоимость: товар + доставка + страхование + пошлина + НДС + прочие расходы.

Это учебная модель. Она не учитывает все возможные сборы, льготы, акцизы, корректировки таможенной стоимости и особенности налогового учёта. Для решения о закупке проверьте расчёт с таможенным представителем.
